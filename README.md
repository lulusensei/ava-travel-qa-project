# AVA Travel – QA Personal Project

## Project Overview
This is a personal Quality Assurance project focused on manual testing of the AVA Travel mobile application on Android and iOS platforms.

## Objectives
- Apply a structured QA methodology on a real-world mobile application
- Identify functional and usability defects
- Practice test design, execution, and defect reporting
- Provide actionable feedback for product improvement

## Scope
- Platforms: Android, iOS
- Testing type: Manual testing, exploratory testing
- Out of scope: Backend, security penetration testing

## Tools Used
- GitHub
- Mobile devices (Android / iOS)
- Screenshots & screen recordings
- Manual test documentation

## Project Structure
- Context definition
- Risk analysis
- Test planning
- Test cases
- Test execution evidence
- Bug reports
- Final recommendations
